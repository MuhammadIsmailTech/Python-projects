### A Smart Voice + Text Assistant built with Python  
Your personal AI-powered assistant that listens to your voice, processes your request, and responds — either through voice or text. It can search the web, open apps, tell the time, summarize information, or chat conversationally.

---

## 📘 Overview

This project demonstrates how to integrate **voice recognition**, **text-to-speech**, and **AI responses** using Python libraries and APIs.

It has two modes:
1. **Voice Mode** – Speak commands using your microphone.  
2. **Text Mode** – Type queries directly into the console.

### ✨ Key Features
- 🎤 Speech-to-text using `SpeechRecognition`
- 🧠 AI-powered answers (via OpenAI API)
- 🔊 Text-to-speech responses with `pyttsx3`
- 🌐 Can search Google or Wikipedia
- 💬 Switch between voice and text input
- 🪶 Lightweight and easy to extend
