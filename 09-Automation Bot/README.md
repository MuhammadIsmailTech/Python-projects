# 🤖 Automation Bot (Python)

A desktop automation bot built with Python.  
It performs file operations, browser automation, screenshots, mouse control, and more.

## 🚀 Features
- Create folders and files  
- Rename or delete items  
- Take screenshots  
- Google search automation  
- Open websites  
- Mouse movement demo  
- Keyboard/mouse automation
